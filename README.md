# api_embargos
Script desenvolvido para api de embargos da SEMAD-GO.
Introdução: O embargo é uma das principais sanções administrativas contra o desmatamento ilegal: embargando a área, busca interromper o dano e permitir a recuperação da vegetação (Brasil, 1981, 1998). A efetividade, no entanto, depende de uma pergunta simples, mas raramente respondida: o embargo está sendo cumprido? Têm-se poucos estudos (Fonseca; Ruschel, 2021) e a verificação esbarra na escala. Em Goiás, estado quase inteiramente no Cerrado, segundo bioma mais desmatado do país (INPE, 2026). Atualmente, 6.294 processos de embargo estaduais e mais de 22 mil polígonos. Verificar cada área manualmente ou in loco é lento e sujeito a critérios diferentes entre análises. Este estudo apresenta e avalia uma ferramenta automatizada, desenvolvida no Google Earth Engine (GEE) e integrada ao QGIS, para responder a essa pergunta de forma rápida, padronizada e rastreável. Metodologia: A ferramenta funciona como uma interface de programação (API) no GEE (Link). A partir do código do processo, a API localiza o polígono embargado e reúne automaticamente três tipos de evidência. A primeira é visual: imagens Sentinel-2 anuais (2018–2025), livres de nuvens, em cor natural e em índice de vegetação EVI (Huete et al., 2002), além dos mapas de uso e cobertura do MapBiomas. A segunda é estatística: a série mensal e anual de EVI da área, com tendência estimada por métodos robustos a valores atípicos e à sazonalidade (Sen, 1968; Hirsch; Slack, 1984). A terceira é um diagnóstico por regras explícitas, que classifica a área como "indício de possível descumprimento", "compatível com regeneração", "atenção" ou "série insuficiente". Tudo é consolidado em um relatório. Quando são necessárias peças adicionais, os dados seguem para o QGIS, onde plugins padronizam a produção de mapas. Resultados: A ferramenta transforma uma tarefa manual de busca e organização de imagens em uma consulta única. Para qualquer um dos 6.294 processos, cada consulta gera 16 imagens anuais, até oito mapas de uso e cobertura, duas séries temporais com tendência e significância estatística, dois diagnósticos e um relatório com metadados e fontes, além de 16 arquivos GeoTIFF e uma tabela de dados (Relatório). A API já é utilizada como ferramenta para verificar amostras de embargos com indícios de descumprimento no órgão ambiental. Na confecção de produtos cartográficos, os plugins (link) reduziram o tempo estimado por mapa de 30 para 15 minutos. Discussão e Conclusão: A API permite acompanhar de forma sistemática, e não apenas quando há denúncia ou vistoria. Há três ganhos para a fiscalização: 1. Todos os processos são analisados com os mesmos critérios; 2. Cada conclusão pode ser rastreado até as imagens e os parâmetros que a sustentam; 3. As áreas com sinais de uso, quando necessário, podem ser priorizadas para ação em campo. A ferramenta, porém, indica indícios, não infrações. A queda de vegetação pode resultar de diversos fatores, necessitando sempre a análise humana na tomada de decisão. Por isso, o diagnóstico orienta, mas não substitui, a análise técnica e a vistoria. O próximo passo é inserir índices de vegetação que possam contribuir com a análise de indícios de descumprimento de embargo.
